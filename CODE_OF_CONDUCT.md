# Code of Conduct
## Our pledge
We are committed to making participation in Ride Efficiency Mobile welcoming and respectful for everyone, regardless of background, identity, experience, or point of view.

## Expected behavior
- Be considerate, respectful, and constructive.
- Focus feedback on ideas and code, not people.
- Accept responsibility, learn from mistakes, and help keep collaboration healthy.

## Unacceptable behavior
Harassment, discrimination, personal attacks, intimidation, and publishing another person's private information without consent are not acceptable.

## Enforcement
Project maintainers may edit or remove contributions and may restrict participation for behavior that violates this code. To report an issue, contact the repository maintainers privately through the contact method listed in the GitHub repository profile. Reports will be handled as confidentially as possible.

This code of conduct applies to project spaces, pull requests, issues, and other project-related communication.
